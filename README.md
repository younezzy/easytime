## 🕑 EasyTime — Chronomètre, minuteur, alarmes
Inspiré de l'application Horloge sur Windows 11, **EasyTime** est conçu pour fonctionner directement dans le navigateur sans nécessité d'installation. 
EasyTime permet, contrairement aux alternatives en ligne, de profiter d'une expérience fluide, moderne et agréable, sans publicité, sans popup intrusive et avec une interface adaptée à tous les supports.

Essayez la version en ligne [en cliquant ici](https://horloge-facile.vercel.app/)

---
### Installation (déployment en local)

1. **Télécharger le projet**

2. **Installer les dépendances** :
   ```bash
   npm install
   ```

3. **Lancer l'application** :
   ```bash
   npm run dev
   ```
